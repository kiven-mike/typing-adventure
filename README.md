# 打字大冒险 · Fairy Typing Adventure

> 一款给小朋友（男孩女孩都爱玩）的 **通用打字练习游戏**。
> 把叶罗丽的仙气、CF 的枪战、热血传奇的刀光，全塞进 12 个关卡里 —— 孩子以为在打游戏，其实在练键盘。

🎮 **打开 `index.html` 就能玩，零安装、零依赖、断网也能跑。**

---

## 这是什么

传统打字软件的问题是：孩子坐不住。
这个项目的思路是：**把打字变成打怪**。

| 你以为在玩 | 实际在练 |
|---|---|
| 开枪打生化幽灵 | 键盘定位（f / j 基准键） |
| 开炮轰坦克 | 中间排字母 |
| 戳爆气球 | 上排字母 |
| 敲地鼠 | 下排字母 |
| 拼音接龙 | 汉字 → 拼音 |
| 赛车冲刺 | 整句拼音输入 |

按对键 → 有反馈（命中、掉血、爆特效）；按错 → 有代价（漏怪、被打、减速）。
孩子为了赢，自己就会越打越快。

### 四场“真实游戏”关卡

- **第 1 关 · 生化来袭**：CF 生化幽灵从远处逼近，越走越近、越走越大。打对字母开枪命中掉血，打偏它就趁机贴脸抓你（掉护甲）。打光血条击倒，共 5 只。
- **第 4 关 · 生化暴君**：CF 挑战模式 BOSS 战。BOSS 满血，每打完一个拼音词就扣一格血；BOSS 每 5 秒反击一次，你得在它打光你之前干掉它。
- **第 5 关 · 卡丁车冲刺**：每完成一句拼音，赛车冲刺一段并喷氮气；对手车同时前进，别让它先到终点。
- **第 7 关 · 传奇沙巴克**：金甲战士持屠龙刀砍祖玛教主。连击 5 次触发**半月弯刀**，连击 10 次触发**烈火剑法**，教主每 6 秒反击。

## 怎么玩

1. 双击 `index.html`（推荐 Chrome / Edge，需支持 Canvas 与 CSS 动画）
2. 选关 → 看屏幕下方虚拟键盘的**手指提示**
3. 按对就得分、连击、放技能；按错不会有惩罚性打断，可以继续

**专为小朋友做的设计**

- 大小写不敏感，不用学 Shift
- 按错不锁死输入，直接按对的那个键就行
- 每关都有常驻任务条，写着“这一关要做什么、做到哪了”
- 虚拟键盘 + 手指分区图，不认识键位也能找到
- 音效可关（右上角）

## 技术

- **单文件网页**：`index.html`（约 1 MB）+ `assets/` 图片素材
- **零依赖**：没有 npm、没有构建、没有外部 CDN，双击即开
- **Canvas 粒子引擎**：水花、火花、爆炸、飘字
- **WebAudio 合成音效**：不加载任何音频文件，全靠振荡器实时合成
- **逐帧动画**：游泳关用 8 帧 sprite + `steps()`，僵尸/赛车用 CSS 关键帧 + JS 时间轴
- **本地存档**：`localStorage` 记录星星、连击、错键统计

```
typing-game/
├── index.html          # 全部游戏逻辑 + 样式（单文件）
├── assets/             # 真实游戏图素材（已抠图）
└── README.md
```
